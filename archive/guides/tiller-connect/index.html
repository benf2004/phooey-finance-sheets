Keep your Tiller workbook.

Bring new transactions and balances into the Google Sheet you already use. Estimated Quarterly Tax, Business Dashboard and Spending Trends can keep reading the same tabs.

Download the Sheets connector

Connect a copy

  1. Open your original workbook in Google Sheets and choose File → Make a copy. Start from the native Google Sheet so its formulas and charts carry over. Use a copy without an active Tiller fill. Choose a first sync date after the last Tiller transaction and balance for the accounts you plan to map.
  2. In your Phooey dashboard, open Settings → Connections → AI & MCP access → Create access token. Name it “Tiller workbook” and select only finance:read. Copy the token.
  3. Unzip the download. Create a private standalone Apps Script project under your Google account. Paste Code.gs into the editor. In Project Settings, turn on Show appsscript.json manifest file in editor. Replace the manifest with the downloaded appsscript.json and save. The manifest enables the Google Sheets advanced service. If you use a custom Google Cloud project, enable the Google Sheets API in that project too.
  4. Under Project Settings → Script properties, enter the four values below. Keep the script private because its editors can access the token.
Property What to enter
WORKBOOK_URL The full Google Sheets URL of your copy
PHOOEY_ORIGIN The HTTPS address of your signed-in ledger, through the domain, without a trailing slash
READ_TOKEN The read-only Phooey token you just created
FIRST_SYNC_DATE The first day Phooey should supply, in YYYY-MM-DD format
  1. Choose prepareWorkbook in the Apps Script editor and click Run. Approve Google's access prompt for your private project. In your workbook, open Phooey Account Map. For each USD account, paste its existing Account ID from Balance History, enter NEW for a new account, or leave it blank to skip it. Balance History may be under View → Hidden sheets.
  2. Run previewSync and check the counts in the execution log. Then run syncWorkbook. Check Transactions, Balances and your quarterly report. Run enableDailySync when you want automatic refreshes. To stop, run disableDailySync and revoke the token in Phooey. Replace expired tokens in the script properties.

How the reports get their numbers

Posted purchases, deposits and split allocations go into Transactions. Balance observations go into Balance History under the mapped account IDs. Existing categories keep the group, type and tags you chose in Sheets. The connector adds any missing categories and a Tags column when needed.

Estimated Quarterly Tax uses the workbook’s tax year, filing settings and category tags. On Categories, check that each applicable Income or Expense category has the Business tag. Use separate categories for business and personal portions. Open the report to review its tax rates and payment dates for the year.

Transaction Tracker, Business Dashboard, Spending Trends, Accounts, Balances and other formula-based tabs continue to use those feed tables. Archived tax sheets keep their formulas and year settings. On uncategorized transactions, the connector recognizes AutoCat’s description, account and institution contains rules and amount minimums and maximums. Other rules that depend on Tiller’s add-on still require that add-on.

Sync runs from Phooey to Sheets. Edit posted amounts and splits in Phooey. The connector supports up to 5,000 allocations and 5,000 balance observations per feed. Older Phooey installations supply current balances at each refresh. If you are starting from scratch, you can also use the free Phooey workbook.

When a new account is missing from Balances

On the Accounts tab, inspect F1 if it contains the “Unique Account Identifier” array formula. A #REF! error naming F2 or another cell below it means a value is blocking the formula. In your working copy, save the named cells’ contents elsewhere, then clear just those blocking cells. Leave F1 in place. The account names and balances should populate automatically.

Add a business report

The connector download includes Foundation.gs. Add that file to your private script project and run addBusinessDashboard or addQuarterlyEarnings. Each report reads your existing categories and transactions. An existing report with that name stays in place.
